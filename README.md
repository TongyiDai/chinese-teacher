# Chinese Teacher / 中文老师

一个写中文工作文档的 AI skill。不是"帮你写得更正式"，而是**让文档有判断力、有人味、能推动决策**。写文档时自动在开头、关键章节和结尾插入飞书画板做视觉摘要——不靠复杂图表，用简约的形状和文字把关键信息亮出来。

## 它解决什么问题

中文工作文档有两个常见病，我自己写文档时也经常犯：

1. **AI 味太重**。读起来像机器生成的——无菌、无体温、无判断。"经综合评估，我们建议可以考虑……"——谁在说话？说了什么？为什么要考虑？三句话，没有一句有信息量。

2. **要么太冷，要么太水**。太冷的文档读完不知道谁写的、怎么想的；太水的文档读完不知道重点是什么、下一步做什么。

这个 skill 试图解决这两个问题。它把公开文档风格指南（Google、Microsoft、GitHub）、MBB/四大/HR 咨询机构的中文原生报告、以及我自己的写作习惯，压成了一套可以复用的规则。

## 四种文风

不是我拍脑袋想出来的，是从实际写作场景中长出来的：

| 风格 | 问题 | 适用 |
| --- | --- | --- |
| **默认风格** | 读者能不能快速看懂、知道做什么 | 周报、纪要、日常方案 |
| **同事风格** | 读起来像不像同事在说话，有没有从业务出发 | 对客方案、客户培训、对内思考 |
| **咨询风格** | 读起来是否专业、可信、能推动决策 | 战略方案、行业分析、投资建议 |
| **精神病风格** | 能不能同时做到极度诚实和极度专业 | 内部战略讨论、复盘、敢说真话 |

它们的关系是这样的：

```
默认风格（地基）
  ├─ + 人味 + 从业务出发 → 同事风格
  ├─ + 框架感 + 数据出处 + 方法论透明 → 咨询风格
  └─ + 同事风格的所有诚实 + 咨询风格的所有专业性 + 尖锐度 → 精神病风格
```

默认风格是地基。同事风格和咨询风格是两个独立分支。精神病风格是两者的融合——也是最有张力的一个。

## 怎么用

安装后先运行：

```bash
scripts/doctor.sh --json
```

它会区分本地写作、飞书写入和可编辑画板能力。没有飞书认证时仍可生成本地文稿和 SVG；写入飞书前需要核对目标文档、账号/租户，并在写入后读回验证。

### Agent 使用说明

| 项目 | 约定 |
|---|---|
| 首步 | `scripts/doctor.sh --json` |
| 本地能力 | 中文文稿、风格改写、SVG 画板生成 |
| 可选能力 | `lark-cli`、`lark-doc`、可编辑飞书画板 |
| 无认证时 | 保留本地文稿和 SVG，状态为 `generated` |
| 飞书写入后 | 读回目标文档结构和画板前后文本，状态才是 `verified` |

详细运行和 Lark 约定见 [`references/runtime.md`](references/runtime.md) 和 [`references/lark-cli.md`](references/lark-cli.md)。

装好之后，当你让我写文档时，我会先问你用哪种文风。你也可以直接指定：

```
"用同事风格改这份客户方案"
"用咨询风格写这份行业分析"
"用同事风格 + 咨询风格写这份方案"
"用精神病风格写这份复盘"
```

## 画板：不只有文字

默认会在文档的三个关键位置生成飞书画板——**开头**（封面页）、**关键章节**（核心框架或数据）、**结尾**（结论 + 行动号召）。画板风格跟随你选的文风。生成的是可编辑的飞书原生画板，不是截图，不用打开别的工具就能改。

画板能力来自 zara 的 [beautiful-feishu-whiteboard](https://github.com/zarazhangrui/beautiful-feishu-whiteboard)（24 种配色风格 + 画板硬规则），已经直接内嵌在这个 skill 里了，不需要额外装任何东西。

## 规则来源

这个 skill 没有凭空编造规则。每条规则下面都有出处：

- **默认规则**：提炼自 Google Developer Documentation Style Guide、Microsoft Style Guide、GitHub Docs，压成适合中文工作文档的写法。
- **咨询风格**：分析了美世、怡安、德勤、普华永道、麦肯锡、BCG、贝恩的中文原生报告（不是翻译件），从中提炼出结构、句式、数据使用习惯。
- **同事风格**：从我自己的 15 篇飞书文档中提炼出的写作模式——包括 10 篇对客方案和 5 篇对内思考。
- **精神病风格**：不是真精神病。是"人味 + 咨询"的极端融合——一个不躲在机构后面、敢下判断、有数据底气、说话带刺但每句话都站得住的写作者。

## 不是什么

- 不是"写得更好看"的美化工具。如果不需要下判断、不需要推动决策，用默认规则就够了。
- 不是邮件、IM、营销文案的写作工具。它就是给工作文档用的。
- 不是我一个人的风格。默认风格和咨询风格是两个独立分支，你可以选你需要的。

## 前提

通用的 AI agent skill，不绑定特定平台。TRAE CLI、Claude Code、Cursor、Codex 或者其他 agent 工具都可以用。需要配合 `lark-doc` skill 来实际创建和更新飞书文档。画板功能需要 `lark-cli` 认证。
