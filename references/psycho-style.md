# Psycho Style：人味 × 咨询的融合风格

"精神病风格"不是真的精神有问题。它是**一个不躲在机构后面、敢下判断、有数据底气、说话带刺但每句话都站得住**的写作者。

这个名字的由来：当一个人同时做到"像咨询顾问一样专业"和"像活人一样诚实"，在中文工作文档的语境里，他看起来就像个精神病——因为其他人都在假装客观、假装全面、假装没有个人观点。

## 这个风格解决什么问题

中文咨询报告最大的问题不是不够专业，而是**读起来像翻译件**。机构腔 + 翻译腔 = 双重隔膜。读者知道你在说重要的事，但感觉不到说话的人。

精神病风格的目标：**让读者感觉是一个极其聪明的同事，坐在对面，用你能听懂的话，告诉你他看到了什么、怎么想的、你应该怎么办。** 他手里有数据，但他不拿数据砸你。他有判断，但他不装权威。他可能说错，但他不会骗你。

## 核心原则

### 1. 写作者永远在场

不是"本文认为"，不是"经评估"，不是"数据表明"。是**一个人**在说话。

```
❌ 经综合评估，当前市场环境存在一定不确定性，建议审慎推进。
✅ 我看不清。现在有三个信号互相矛盾，我不建议现在做决定。等 Q3 数据出来再看。
```

### 2. 判断先行，证据跟上

先说你到底怎么想的，再说你为什么这么想。不要铺垫，不要"首先让我们回顾一下行业背景"。读者没有耐心。

```
✅ 这个方向是对的，但时间不对。
   三组数据支撑这个判断：……
```

### 3. 尖锐需要本钱

你可以说狠话，但每句狠话后面必须跟一个事实。没有事实的尖锐是噪音，有事实的尖锐是判断力。

```
❌ 竞品完全是瞎搞。（没有事实，等于没说）
✅ 竞品这样做是有问题的。他们上个月改了定价策略，但流失率反而涨了 15%。方向可能没错，但执行出了问题。
```

### 4. "我"和"我们"不混用

- 个人判断、直觉、价值取向 → "我"
- 基于数据、调研、团队共识的结论 → "我们"

```
我倾向于方案 A，不是因为 A 最完美，而是因为 B 和 C 有硬伤。
我们的调研覆盖了 500 家企业，数据显示……
```

同一篇文档里两种都用，这是正常的。只要读者分得清哪些是你的个人判断，哪些是集体结论。

### 5. 诚实到让人不舒服

```
✅ 我不知道这个数字准不准，来源是第三方，我们没有自己验证过。但方向是对的。
✅ 我之前的判断错了。当时我认为用户会在意价格，但数据表明他们在意的是响应速度。
✅ 这个问题我还没想清楚。给我两周，我跑完数据再告诉你。
```

### 6. 节奏是武器

短句是匕首，长句是重剑。交错使用。

```
这个项目，方向对，但执行有问题。

过去三个月，我们做了三件事：改版首页、优化搜索、上线推荐。页面浏览量涨了，但转化率没动。不是流量的问题，是产品的问题。

具体来说，用户来了，看了，走了。他们没找到想要的。推荐算法准确率 43%，这意味着超过一半的推荐是无效的。
```

## 句式工具箱

### 破冰式开头

不说"本文旨在"，直接给结论。

```
这个判断可能会让一些人不太舒服，但数据不会说谎：……
我跟踪这个行业三年了，这是我第一次感到乐观。原因是……
先说结论：我们建议不做。原因有三。
```

### 直接下判断

```
我看下来，核心问题是……
我不太同意这个方案。分歧在于……
我倾向于……不是因为它最好，而是因为其他选项更差。
这里有一个反直觉的发现：……
我不确定，但我的直觉是……（后面跟一句"为什么"）
```

### 说"我不知道"的花式表达

```
这个数据我没拿到，先空着，下周补。
这块我不专业，我的判断可能不准，建议找 XX 确认。
目前有两种可能，证据都不够强，我倾向于 A，但只有六成把握。
我之前的判断可能错了，等结果出来再看。
```

### 尖锐判断（带事实弹药）

```
这个方案看起来很完整，但有一个致命问题：……
不是他们不想做，而是他们做不到。原因很简单：……
市场在说一件事，但数据在说另一件事。我选择相信数据。
这个行业最大的谎言是……（后面跟证据）
```

### 收尾

```
我还需要以下信息才能做最终判断：……
如果必须现在做决定，我选 A。理由如上。如果错了，损失可控。
以上是我的判断。不一定对，但我目前只能看到这些。
```

## 反面教材：精神病风格 vs 假精神病风格

真正的精神病风格是有事实支撑的尖锐。假的精神病风格是情绪化的、没有事实的、表演性的。

### 真正的精神病风格

```
这个季度业绩不理想，但我不担心。

营收降了 12%，但这不是需求的问题——同期用户活跃度涨了 8%。问题出在转化环节，新用户注册后 48 小时内流失率 67%，比上季度高了 9 个百分点。这才是要害。

如果我们把注册流程从 5 步减到 3 步，根据 A/B 测试数据，流失率预计能降 20%。这个改动两周能上线。

我判断 Q4 可以翻正。
```

### 假的精神病风格

```
这个季度简直是灾难，我也不知道该怎么办。市场太差了，竞争对手太强了，我们太弱了。可能我们真的不行了。
```

区别：真的给数据、给判断、给路径。假的给情绪、给表演、给绝望。

## 适用场景

| 场景 | 适合程度 | 说明 |
| --- | --- | --- |
| 战略建议、投资判断 | 高 | 决策者需要的不只是信息，是判断。这个风格最适合。 |
| 行业分析、竞品分析 | 高 | 需要有观点、有判断，不能只是"综述"。 |
| 复盘、事后分析 | 高 | 诚实是复盘的生命。这个风格天然适合。 |
| 方案、提案 | 中 | 可以，但要根据受众调整尖锐程度。给老板的可以更尖锐，给跨部门协作的稍微收敛一点。 |
| 周报、进展同步 | 中 | 可以，但不要过度。周报的核心是信息同步，不是展示判断力。 |
| 公告、通知 | 低 | 不适合。公告需要正式、准确、无歧义。 |
| 对外公开发布 | 低 | 不适合。这是内部沟通风格，对外需要不同的语气。 |
| 合规文件、法律文件 | 不适用 | 这些需要精确术语和正式格式，不是风格问题。 |

## 一句话总结

**精神病风格 = 人味风格的所有诚实 + 咨询风格的所有专业性 + 敢于让两者同时出现。**

这不是一个"中间风格"，而是一个更难的风格。它要求写作者同时做到两件难事：像咨询顾问一样严谨，像活人一样真实。能做到的人不多，但能做到的人，写出来的东西会让人记住。

## 与其他风格的关系

精神病风格是同事风格和咨询风格的融合体。与同事风格在对内文档中高度重合，区别在于精神病风格允许更尖锐的表达。与默认风格、同事风格、咨询风格的关系及组合使用的方法，见 SKILL.md 中的"风格之间的关系"部分。
