# Consulting Style：咨询顾问的写作风格

这个文件是从三类咨询机构的中文原生报告中提炼出的写作风格规则。它不只是"怎么写"，更是"怎样让读者觉得你专业、可信、有判断力"。

## 来源

以下分析基于实际抓取的各机构中文原生报告（非翻译件）：

- **HR 咨询**：美世（Mercer）薪酬调研报告、怡安（Aon）领导力报告
- **四大**：德勤（Deloitte）消费品零售行业纵览、普华永道（PwC）CEO 调研中国报告
- **MBB**：麦肯锡（McKinsey）中国消费报告、BCG 财富管理报告/AI 报告、贝恩（Bain）中国奢侈品市场报告

## 1. 咨询风格的底层逻辑

咨询报告和普通工作文档的核心区别：**咨询报告的目标不是"说明情况"，而是"建立信任并推动决策"。**

读者读咨询报告时，心里有三个问题，顺序不能乱：

1. 这人懂不懂？ → 专业度
2. 这数字靠谱吗？ → 可信赖度
3. 那我该怎么办？ → 务实度

如果第一页没回答"这人懂不懂"，读者就不会读第二页。如果数据来源不透明，读者就不会相信你的结论。如果结论没有转化为行动建议，读者就觉得"说得对，但跟我有什么关系"。

咨询风格的所有规则，都是围绕这三个问题展开的。

## 2. 结构：让读者在 30 秒内信任你

### 2.1 开头三板斧

所有咨询报告的开头都遵循同一个模式，不管叫"摘要"还是"内容提要"还是"核心发现"：

**第一板斧：最核心的判断。** 一句话说清你的结论。不是"本文分析了中国消费市场"，而是"中国消费市场正在步入以个位数增长为特征的'新常态'"。

**第二板斧：支撑这个判断的关键数据。** 2-4 个数字，不能多。麦肯锡消费报告开头："调查对象涵盖 17,000 多名中国消费者""将消费者细分为 108 个不同群体"。

**第三板斧：读者为什么要在乎。** 这个判断意味着什么、对谁有影响。

示例（贝恩奢侈品报告的开头）：

```
内容提要
• 奢侈品牌亟需在创意、品牌价值感、定价、运营等方面制定清晰的策略和执行方案。
• 贝恩认为，当下的困境并不会削弱中国内地市场对于奢侈品牌的吸引力。
• 长期来看，中国市场庞大的奢侈品消费群体仍然是全球奢侈品消费的重要增长引擎。
```

三个 bullet，分别回答了：做什么、为什么还值得做、长期怎么看。

### 2.2 正文结构：从大到小，逐层展开

咨询报告的正文结构是"望远镜 → 放大镜 → 显微镜"：

1. **宏观判断**：行业/市场整体趋势（麦肯锡：三大趋势）
2. **中观分析**：分行业、分区域、分品类（德勤：白酒、宠物食品、化妆品表现强劲，啤酒、畜牧养殖和乳制品增长放缓）
3. **微观洞察**：具体企业、具体案例、具体数据点
4. **行动建议**：对谁、做什么、什么时候

### 2.3 每个 section 必须是"判断 + 证据"

不要只给数据，也不要只给观点。每一个 section 的结构是：

```
判断 → 数据/事实 → 解读（为什么是这个判断）→ 影响（所以呢）
```

麦肯锡示例：

```
判断：消费者接纳新常态，顺势而为
数据：2024年及2025年Q1，GDP持续保持约5%增长。2025年消费增长预期2.3%。
解读：这一增长率主要得益于城镇化推进和消费占收入比重保持稳定。
影响：虽然指标积极，但受到家庭收入增长更为温和的预期影响。
```

### 2.4 标题要有信息量

咨询报告的标题是"关键词 + 判断"，不是"主题陈述"。

| 差的标题 | 好的标题 |
| --- | --- |
| 关于中国消费市场的分析 | 新常态下的中国消费：三大趋势重塑市场格局 |
| 2025年薪酬调研 | 2025中国市场薪资增长率预计为4.4% |
| 零售行业纵览 | 挖掘消费结构升级中的增长新机遇 |
| AI 在工作中的应用 | AI是创新力放大器，中国采用率达87%居全球前列 |

## 3. 专业度：怎样写才像"懂行的人"

### 3.1 方法论透明

所有顶级咨询报告都会在开头或脚注中交代方法论。这不是为了炫耀，而是为了让读者判断你的结论是否可靠。

- 美世："美世整体薪酬调研结果基于近 4,000 家中国参调企业的回复。"
- 麦肯锡："麦肯锡中国消费与零售咨询业务在中国进行了一项全国性调查，调查对象涵盖 17,000 多名中国消费者。我们根据城市等级、年龄、家庭收入等因素，将消费者细分为 108 个不同群体。"
- 德勤："深入研究了超过 550 家消费品零售上市公司的绩效，通过对比分析各细分领域领先企业的表现。"

方法论至少包含三个要素：**样本量、样本来源、分析方法**。缺一个，读者就不踏实。

### 3.2 命名专家，不匿名

咨询报告从不写"相关专家表示"。每个观点都有出处、有名字、有 title。

- 美世："美世中国区资深合伙人曹燕萍女士表示"
- 麦肯锡："泽沛达（Daniel Zipser），麦肯锡全球资深董事合伙人，亚洲消费与零售咨询业务负责人"
- 贝恩："贝恩公司资深全球合伙人布鲁诺（Bruno Lannes）表示"
- 德勤："德勤亚太消费品及零售行业主管合伙人张天兵表示"

如果引用的是外部数据，同样标注来源："根据中国人民银行（PBOC）2024年第二季度调查""根据瑞银《2025年亿万富豪报告》"。

### 3.3 引用对标，提供参照系

孤立的数字没有意义。咨询报告总是在比较中呈现数据：

- 时间序列对比："2024年上半年主动离职率（3.9%）比去年同期（4.9%）有所下降"
- 区域对比："一线城市对于2025年的薪资增长预期差异不大，在4.4%-4.6%之间"
- 行业对比："高科技行业和生命科学行业均为4.8%，高于其他行业"
- 全球对标："中国的AI采用率以87%位居前列，远超全球对标水平的72%"

### 3.4 概念框架命名

咨询机构擅长给复杂现象起一个简洁的名字，让读者容易记住、容易转述：

- 麦肯锡："新常态"（用在消费市场）
- BCG："结构性洗牌""枢纽-辐射结构""4I领导力"
- 怡安："务实增长"
- 德勤："消费结构升级"

这些不是空洞的 buzzword，而是对复杂现象的压缩。一个好的概念框架 = 一个判断 + 一个可记忆的名字。

## 4. 细节度：数字、名字、时间的力量

### 4.1 数字要精确，区间要诚实

咨询报告的数字有三个特点：

**精确到小数点后一位。** "4.3%"不是"约4%"。"下降18%-20%"不是"大幅下降"。精确度本身就是可信度的信号。

**不确定时用区间。** 贝恩："预计下降18%-20%""占中国消费者奢侈品消费总额的比例提高至40%左右"。区间不是模棱两可，而是诚实——当数据无法精确到个位数时，给出合理范围。

**大数字和百分比同时出现。** "超过 550 家消费品零售上市公司"（规模感）+ "总体市值规模达到 14.4 万亿人民币"（重要性）。

### 4.2 名字要有全称

- "美世中国区资深合伙人曹燕萍女士" → 不是"美世相关负责人"
- "中国人民银行（PBOC）" → 不是"相关监管部门"
- "德勤亚太消费品及零售行业主管合伙人张天兵" → 不是"德勤专家"

具体的名字让读者可以验证、可以追问、可以信任。

### 4.3 时间要精确

- "2024年上半年"不是"近期"
- "2025年1月21日"不是"日前"
- "2024年10月1日至11月9日"不是"前段时间"

时间戳让读者知道这个信息是多新的，也让他们能判断时效性。

## 5. 务实度：从洞察到行动

### 5.1 每个判断都要有"所以呢"

咨询报告不做"纯描述"。每个发现后面一定跟一个"这意味着什么"。

- 麦肯锡："虽然这些百分比变化看起来并不显著，但换算成绝对数字时，则意味着相当可观的增长。"
- BCG："那些仍然依赖市场上涨带来收入的机构，实际上是在温水煮青蛙，等到市场转向时，才会发现自己的商业模式已经过时。"
- 贝恩："报告强调，在当前宏观经济环境不确定的背景下，迅速响应并采取行动以调控全球价格，是奢侈品高管团队任务的重中之重。"

### 5.2 行动建议要具体

- "奢侈品牌亟需在创意、品牌价值感、定价、运营等方面制定清晰的策略和执行方案" → 四个维度，不是一句"需要提升竞争力"
- "如果本周五前无法完成数据回填校验，上线后会出现历史记录缺失。当前由数据团队补跑校验，结果预计周四晚确认。" → 有 owner、有 deadline、有后果

### 5.3 风险要说清楚三件事

咨询报告不提空泛的风险。每个风险至少包含：

1. 触发条件（什么情况下会发生）
2. 影响（发生了会怎样）
3. 当前应对（现在在做什么）

贝恩示例："海南免税市场面临的不确定性依然存在：一方面，海南预计 2025 年底实现全岛封关；另一方面，海南依然面临着内地市内免税店扩张以及邻近市场的抢客压力。"

## 6. 可信赖度：诚实是最好的策略

### 6.1 主动说"不确定"

最好的咨询报告敢于说"我们不知道"或"这取决于"。

- 麦肯锡："近期中美贸易争端的升级，为企业和消费市场再添变数。这是一个至关重要的话题，我们将持续密切关注其进展。"
- BCG："固守传统思维可能错过历史性机遇。"
- 贝恩："2025年上半年中国内地奢侈品市场依然会面临挑战，但我们对下半年的市场前景持谨慎乐观态度。"

"谨慎乐观"本身就是咨询行业最经典的可信表达——不绝对、不煽动、不回避。

### 6.2 正反两面都写

麦肯锡消费报告："虽然这些指标积极，但受到家庭收入增长更为温和的预期影响。中国消费者对2025年家庭收入增长率的平均预期仅为1.4%，低于2024年的2.5%。"

先说好的一面，再说不好的一面。读者不会因为看到负面信息而不信任你，反而会因为看到你回避负面信息而不信任你。

### 6.3 数据来源可追溯

- "根据2024美世整体薪酬调研" → 不是"数据显示"
- "根据中国人民银行（PBOC）2024年第二季度调查" → 不是"据调查"
- "Re-Hub 的数据显示" → 不是"据了解"

如果数据来自第三方，必定标注来源。如果数据来自自己的调研，必定说明方法论。

## 7. 人味：咨询顾问也是人

### 7.1 MBB 式人味：尖锐、自信、有判断

BCG 是最典型的范例。他们的报告不回避尖锐判断：

- "当大多数财富管理机构还在为规模增长沾沾自喜时，BCG 在最新报告中投下了一颗战略震撼弹。"
- "把新兴市场当作成熟市场的延伸，是财富管理机构最大的战略误判。"
- "这种商业模式在牛市中看起来很美好，但在市场波动时就会原形毕露。"

这种"人味"来自**敢于下判断、敢于说狠话、敢于提出不同意见**。它不是情绪化，而是基于专业分析后的自信表达。

麦肯锡的"人味"更克制，但不隐身：

- "我们的最新研究显示，尽管挑战依旧存在，但实际情况远非某些观察人士所描述的那般黯淡。"
- "我们相信，本次调研的发现对于在这个瞬息万变市场中的决策者而言，依然具有重要借鉴意义。"

"我们相信""我们判断""我们认为"——写作者在场，但不喧宾夺主。

### 7.2 四大式人味：专业、务实、有温度

德勤的专家引用不是冷冰冰的背书，而是带有观点的表达：

- 张天兵："理性、实用主义盛行，中青年消费者开始选择可持续的生活和消费方式。"
- 陈岚："近六成消费者关注绿色、低碳、可持续发展的线下店铺，表明企业不仅需开发绿色产品，还需打造绿色消费新场景。"

### 7.3 HR 咨询式人味：数据驱动、以人为本

美世的专家引用：

- 曹燕萍："中国经济正处于从高速发展向高质量发展的转型期，这一过程中面临着诸多挑战与困难。……企业应把握机遇，加强内功的修炼，从组织结构、奖酬体系、激励体系、人才培养、效能提升、能力建设等多个维度强化自身实力。"

HR 咨询的"人味"体现在**对人的关注**——不只是数字，还有数字背后的人。薪资增长率不只是经济指标，它关系到每一个员工的生计。

### 7.4 三种人味的共同点

不管哪种咨询风格，"人味"都来自：

1. **写作者有判断**。不是"数据表明"，而是"我们基于数据判断"。
2. **写作者有名字**。每个观点有出处，不是匿名机关。
3. **写作者会设身处地**。"这对你意味着什么"——咨询报告始终在回答读者的隐含问题。
4. **写作者敢说"不一定"**。诚实比永远正确更可信。

## 8. 三种咨询机构的风格差异

### 8.1 MBB：战略级、判断力强、框架感突出

- **语言风格**：自信、尖锐、有观点。不回避争议性判断。
- **结构特征**：重框架（"三大趋势""四类玩家""五种路径"），重概念命名。
- **数据使用**：用数据支撑判断，但数据不是主角，判断才是。
- **代表句式**："不是 A，而是 B""这标志着……""真正的危机隐藏在……"
- **适用场景**：战略方案、行业分析、投资决策、重大转型建议。

### 8.2 四大：系统级、覆盖全面、落地导向

- **语言风格**：专业、全面、务实。不太冒风险，但也不空洞。
- **结构特征**：重全景覆盖（行业→细分→区域→企业），重方法论透明。
- **数据使用**：数据量大、覆盖广，强调"超过 550 家""总体市值 14.4 万亿"。
- **代表句式**："报告指出……""调研发现……""这一趋势表明……"
- **适用场景**：行业研究、尽调报告、政策分析、合规建议。

### 8.3 HR 咨询：人力视角、数据驱动、温度与专业并重

- **语言风格**：专业但有人情味。数据背后是"人"。
- **结构特征**：先宏观数据（增长率、离职率），再分行业/区域，再趋势解读。
- **数据使用**：精确到小数点后一位，但解读时回到"人"的层面。
- **代表句式**："调研显示……""XX% 的员工……""企业应……"
- **适用场景**：薪酬报告、人才趋势、组织诊断、领导力发展。

## 9. 常用句式与表达法

以下句式是从各机构报告中提取的高频表达，按功能分类：

### 9.1 开篇判断

| 句式 | 来源 | 使用场景 |
| --- | --- | --- |
| ……正在步入以……为特征的"新常态" | 麦肯锡 | 定义新阶段 |
| ……未能延续……势头，预计…… | 贝恩 | 转折判断 |
| 当大多数……还在……时，……已经…… | BCG | 对比式开场 |
| ……发布了……调研结果。其中，…… | 美世 | 客观陈述式开场 |
| ……深入研究了……，通过对比分析……，旨在揭示…… | 德勤 | 方法论前置式 |

### 9.2 数据引入

| 句式 | 来源 | 使用场景 |
| --- | --- | --- |
| 调研数据显示，……。其中，……以 X% 位居…… | BCG | 数据 + 排序 |
| 2024年……为 X%，预计2025年……为 Y% | 美世 | 连续数据对比 |
| X% 的受访者表示……，而全球该比例为 Y% | BCG | 全球对标 |
| 报告揭示，仅 X% 的……表示…… | BCG | 揭示差距 |
| 从数据来看，……占……的比例提高至 X% 左右 | 贝恩 | 占比变化 |

### 9.3 解读与判断

| 句式 | 来源 | 使用场景 |
| --- | --- | --- |
| 这意味着…… | 通用 | 直接解读 |

## 与其他风格的关系

咨询风格是默认风格的"加强版"——它在默认风格的所有规则之上，叠加了更高的要求（数据出处、方法论透明、框架命名等）。当用户要求"咨询风格"时，默认风格的规则仍然适用，但被咨询风格的规则增强。

咨询风格与同事风格、精神病风格的关系，以及组合使用的方法，见 SKILL.md 中的"风格之间的关系"和"风格参考文件"两部分。
